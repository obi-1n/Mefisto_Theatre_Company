# ONnegha Mefisto Theatre Company

This repository contains the source code for the ONnegha Mefisto Theatre Company website, built as an ASP.NET MVC application.

## Overview

The project is a .NET Framework MVC web application for showcasing theatre-related content and managing site functionality through a standard ASP.NET structure.

## Tech Stack

- ASP.NET MVC 5
- .NET Framework 4.7.2
- Entity Framework 6
- Microsoft OWIN / ASP.NET Identity
- IIS / Visual Studio development workflow

## Project Structure

- `ONnegha_Mefisto_Theatre_Company.sln` – Visual Studio solution file
- `ONnegha_Mefisto_Theatre_Company/` – main ASP.NET MVC project
- `App_Start/` – application startup configuration
- `Controllers/` – MVC controllers
- `Models/` – domain and data models
- `Views/` – Razor views
- `Scripts/` – frontend JavaScript assets
- `Content/` – CSS and static resources

## Prerequisites

Before running the project, make sure you have:

- Visual Studio 2019 or later
- .NET Framework 4.7.2 SDK / targeting pack
- IIS Express or a compatible local web server
- NuGet package restore enabled

## Getting Started

1. Clone the repository.
2. Open `ONnegha_Mefisto_Theatre_Company.sln` in Visual Studio.
3. Restore NuGet packages if prompted.
4. Set the web project as the startup project.
5. Run the application using IIS Express or your preferred local web server.

## Build Notes

This project uses legacy ASP.NET project configuration and NuGet package references, so it is best run in a Windows-based Visual Studio environment.
